# Progres Penerapan Desain UI SetorKu (`Ecological Modernism`)

Dokumen ini melacak progres migrasi seluruh view Blade SetorKu ke tema **Ecological Modernism** (`public/css/setorku-theme.css`) dan tiga layout baru (`layouts.ui-staff`, `layouts.ui-nasabah`, `layouts.ui-guest`) sesuai aturan di [docs/ATURAN_PENERAPAN_UI.md](file:///C:/laragon/www/Sistem%20Informasi%20Bank%20Sampah/bank-sampah/docs/ATURAN_PENERAPAN_UI.md).

---

## 1. Perhitungan Faktual View (Hasil Grep `resources/views/`)

Berdasarkan pemeriksaan seluruh file `*.blade.php` di `resources/views/`:
- **Sudah memakai layout baru (`PBI-UI-00` + `Batch 1`)**: **8 view halaman** (`auth/login.blade.php`, `dashboard/admin.blade.php`, `dashboard/nasabah.blade.php`, `auth/google-complete.blade.php`, `dashboard/petugas.blade.php`, `pickups/petugas/index.blade.php`, `pickups/petugas/show.blade.php`, `pickups/petugas/route.blade.php`) + **1 partial pendamping** (`pickups/petugas/_route_map.blade.php`).
- **Masih memakai `@extends('layouts.app')`**: **32 view halaman**.
- **Standalone (`<!DOCTYPE html>`) di luar `layouts/`**: **1 file** (`welcome.blade.php`, view bawaan Laravel tidak terpakai karena `GET /` langsung redirect ke `route('login')`; tetap dipertahankan sesuai aturan larangan menghapus file).
- **Partial (`@include`) pendamping halaman yang belum dimigrasikan**: **4 file** (`customers/_form.blade.php`, `waste-types/_form.blade.php`, `partials/_qr_customer_lookup.blade.php`, `officers/_form.blade.php`).
- **Total halaman aplikasi aktif (Batch 1–5)**: **37 view halaman** (5 selesai di Batch 1, 32 tersisa di Batch 2–5) **+ 5 partial pendamping** (1 selesai di Batch 1, 4 tersisa di Batch 2–4).
